# Hardware Overview

## Overview

SMOOCH is built around a compact embedded platform capable of supporting expressive animations, voice playback, and local interaction.

This repository intentionally omits detailed hardware schematics, PCB layouts, firmware architecture, and manufacturing documentation.

---

## High-Level Components

The current prototype includes:

- Embedded microcontroller
- OLED facial display
- MEMS microphone
- Audio amplifier
- Speaker
- Rechargeable battery
- USB charging
- Motion sensing
- User input button

---

## Capabilities

The hardware platform is designed to support:

- Facial animations
- Audio playback
- Voice interaction
- Motion detection
- Power-efficient idle operation
- Battery-powered portability

---

## Design Goals

- Small form factor
- Low power consumption
- Mass-manufacturable design
- Modular architecture
- Future expandability

---

## Public Notice

Detailed hardware implementation, component selection, PCB design, circuit diagrams, manufacturing files, and firmware integration are proprietary and are not included in this repository.
